# Pika Instagram 内容工作区

这里是 Pika 的 Instagram 内容中枢，用来沉淀每一次内容创意、脚本、Reels POV、剪辑说明与发布复盘。

## 内容导航

- `content-ideas/`：选题、文案灵感与内容方向
- `reels/`：每条 Reels 的 POV、分镜、口播与剪辑说明
- `calendar/`：发布计划和内容状态
- `assets/`：素材链接、封面与参考资料（不存放体积过大的原始视频）
- `templates/`：可复用的内容工作模板

## 工作方式

每次要做内容时，记录：

1. 目标与受众
2. 核心 POV 或创意钩子
3. Caption、屏幕字幕与行动号召
4. 拍摄分镜和剪辑节奏
5. 发布时间、发布链接与复盘结果

> 由 Codex 协助持续整理。
